# キャラクター図鑑

AIイラスト生成（SDXL系サービス想定）で作ったキャラクターの「サムネイル画像」「プロンプト」「ネガティブプロンプト」「生成設定（モデル/サンプラー/LoRA/シード等）」「自由タグ」をまとめて登録・検索・バックアップできる、個人用のプロンプト管理ツールです。

- **利用者**：本人専用（他人とデータを共有する仕組みはありません）
- **実体**：`index.html` 1ファイルのみ（HTML + CSS + JS すべて内包、ビルド不要、外部ライブラリ依存なし。Googleフォントのみ外部読み込み）
- **公開方法**：GitHub Pages

## 主な機能

- サムネイル付きカードグリッドでの一覧表示、キーワード検索、並び替え、タグ絞り込み（複数選択OR）
- 新規登録・編集フォーム
  - サムネイル画像（アップロード時に長辺640pxへリサイズしJPEGとして保存）
  - キャラクタータグ（自由入力）
  - プロンプトの貼り付け→カンマ区切りでタグに自動分割（括弧内のカンマは無視）
  - タグごとにカテゴリを手動 or キーワード辞書によるルールベース自動判定で分類（カテゴリは自由に追加・削除可能）
  - ネガティブプロンプト、生成設定（モデル・サンプラー・ステップ数・CFG Scale・シード・サイズ・生成時間）、LoRA（複数）、メモ
  - 全文プレビュー＋コピー
- 詳細画面（カテゴリ別グループ表示、コピー、編集・削除）
- 旧データ形式（プロンプトがプレーン文字列だった頃）の自動マイグレーション
- JSONエクスポート/インポート（全データのバックアップ・復元、「追加」または「全置き換え」を選択可能）

## データの保存場所（重要）

- 登録データ本体：ブラウザの **IndexedDB**（DB名 `character_library_db`、ストア名 `entries`）
- カテゴリ一覧・自動判定ON/OFF設定：**localStorage**（`char_lib_categories_v1` / `char_lib_auto_classify_v1`）

**端末・ブラウザごとに別データです。** サーバー側で集約する仕組みはなく、キャッシュ削除・シークレットモード・別ブラウザ・別端末ではデータは引き継がれません。個人利用ツールとして意図的にこの設計にしています。

対策として、画面右上の「📤 書き出し」「📥 読み込み」から全データをJSONファイルとしてバックアップ・復元できます。定期的なバックアップを推奨します。

## 使い方（ローカルで開く場合）

`index.html` をブラウザで直接開くだけで動作します。ビルドやサーバー起動は不要です。

```bash
# 例：デフォルトブラウザで開く（Windows）
start index.html
```
