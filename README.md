# キャラクター図鑑

AIイラスト生成（SDXL系サービス想定）で作ったキャラクターの「サムネイル画像」「プロンプト」「ネガティブプロンプト」「生成設定（VAEモデル/Sampling Method/LoRA等）」「自由タグ」をまとめて登録・検索・バックアップできる、個人用のプロンプト管理ツールです。あわせて、Danbooru系プロンプトタグの日本語対訳チートシートも内蔵しています。

- **利用者**：本人専用（他人とデータを共有する仕組みはありません）
- **実体**：`index.html` / `style.css` / `app.js` / `promptDictionary.js` の4ファイル構成（ビルド不要、外部ライブラリ依存なし。Googleフォントのみ外部読み込み）
- **公開方法**：GitHub Pages

## ファイル構成

```
index.html           … マークアップのみ
style.css             … 全スタイル（レスポンシブ対応含む）
app.js                … アプリのロジック一式
promptDictionary.js   … プロンプト辞典（チートシート）のデータ
```

## 主な機能

- サムネイル付きカードグリッドでの一覧表示、キーワード検索、並び替え、タグ絞り込み（複数選択OR）
- 新規登録・編集フォーム
  - サムネイル画像：アップロード時に長辺1600pxへリサイズしJPEGとして保存。位置・拡大率をドラッグ＆スライダーで調整できる非破壊クロップ機能付き（元画像＋変形情報を保持し、表示のたびに計算するため何度でも調整し直せる）
  - キャラクタータグ（自由入力、一覧の絞り込みに使用）
  - プロンプト／ネガティブプロンプト（プレーンテキスト）
  - 「プロンプト辞典から追加」パネル：カテゴリ選択または日本語検索でプロンプト辞典を絞り込み、ワンクリックでプロンプト／ネガティブプロンプトへ追加
  - 生成設定：VAEモデル・Sampling Method・ステップ数・CFGスケール、LoRA（複数）、メモ
- 詳細画面（プロンプト／ネガティブプロンプトはアコーディオンで開閉、コピー、編集・削除）
- **プロンプト辞典（チートシート）ページ**：Danbooru系プロンプトタグを日本語の意味とあわせて検索・カテゴリ絞り込みできる独立ページ（出典：[Danbooru Tag Groups](https://danbooru.donmai.us/wiki_pages/tag_groups)）
- スマホ表示対応（狭い画面では書き出し／読み込みボタンがアイコンのみになる）
- 旧データ形式（タグごとにカテゴリ分類していた頃のプロンプト構造）の自動マイグレーション
- JSONエクスポート/インポート（全データのバックアップ・復元、「追加」または「全置き換え」を選択可能）

## データの保存場所（重要）

- 登録データ本体：ブラウザの **IndexedDB**（DB名 `character_library_db`、ストア名 `entries`）

**端末・ブラウザごとに別データです。** サーバー側で集約する仕組みはなく、キャッシュ削除・シークレットモード・別ブラウザ・別端末ではデータは引き継がれません。個人利用ツールとして意図的にこの設計にしています。

対策として、画面右上の「📤 書き出し」「📥 読み込み」から全データをJSONファイルとしてバックアップ・復元できます。定期的なバックアップを推奨します。

## 使い方（ローカルで開く場合）

4ファイルとも同じフォルダに置いた状態で、`index.html` をブラウザで直接開くだけで動作します（`<script src="...">` は通常の読み込みのため、`file://` の直接ダブルクリックでも問題なく動作します）。

```bash
# 例：デフォルトブラウザで開く（Windows）
start index.html
```

### プロンプト辞典データについて

`promptDictionary.js` は [Danbooru Tag Groups](https://danbooru.donmai.us/wiki_pages/tag_groups) を参考にしたDanbooru系プロンプトタグの日本語対訳集です。エントリを追加・編集する場合は、同ファイル内の配列 `PROMPT_DICTIONARY`（`{ category, code, ja }` の配列）を直接編集してください。
